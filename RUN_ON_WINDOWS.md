# 💻 How to Run WhatsApp AI Sales Agent on Windows Laptop

Follow this simple 3-step guide to run the **WhatsApp AI Sales Agent & OpenWA Gateway** locally on any Windows laptop or PC.

---

## 📋 Prerequisites (One-Time Setup)

1. Download and install **Node.js (v20 or v22 LTS)** from [https://nodejs.org](https://nodejs.org).
2. Download or unzip your project folder on your Windows laptop.

---

## 🚀 How to Launch the Agent

1. Open the project folder on your computer.
2. **Double-click `run-agent.bat`**.
3. The script will automatically start the background services and **open your web browser to `http://localhost:3000`**.

---

## 📱 Linking Your WhatsApp Session

1. Once the browser opens (`http://localhost:3000`), go to **Step 1: Link WhatsApp Session**.
2. Click **Scan QR Code** or enter your phone number to get an 8-digit pairing code.
3. Open WhatsApp on your phone -> **Linked Devices** -> **Link a Device**.
4. Scan the QR code or enter the code to connect your companion line.

---

## 🛑 How to Stop the Agent

- To stop the agent cleanly, double-click **`stop-agent.bat`** or close the launcher command window.
